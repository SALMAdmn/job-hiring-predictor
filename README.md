# Job Hiring Predictor App

## Description
Application de Machine Learning qui prédit les chances d'embauche d'un candidat.

## Technologies
Python
Streamlit
Scikit-learn

## Installation
pip install -r requirements.txt

## Lancer l'application
streamlit run app.py

## Dataset
Dataset simulé basé sur profils étudiants
